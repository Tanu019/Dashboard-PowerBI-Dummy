## 🌟 Overview
This project features a comprehensive **Power BI Dashboard** designed to visualize and analyze online sales data. It provides key insights into revenue, product performance, and customer trends, helping stakeholders make data-driven decisions.

The raw data is managed in Excel and dynamically loaded into Power BI for transformation and visualization.

## ✨ Features
- **Interactive Visualizations:** Deep dive into the data using filters and interactive charts.
- **Sales Analytics:** Track total revenue, quantity sold, and profitability across different segments.
- **Trend Analysis:** Identify seasonal patterns and top-performing products.
- **Clean UI/UX:** A modern, visually appealing layout designed for easy readability.

## 📁 Repository Structure
- `Dashboard(Tanu).pbix` - The main Power BI dashboard file containing all the visuals and data models.
- `Online Sales Data.xlsx` - The raw dataset used for the analysis.

## 🚀 How to Use
1. **Prerequisite:** Make sure you have [Power BI Desktop](https://powerbi.microsoft.com/desktop/) installed on your machine.
2. Clone this repository or download the files.
3. Open `Dashboard(Tanu).pbix` using Power BI Desktop.
4. If prompted to refresh the data, ensure the path points to the included `Online Sales Data.xlsx` file.
